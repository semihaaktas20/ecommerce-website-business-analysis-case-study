# E-Commerce Website Business Analysis Case Study

## Overview
This project analyzes the customer journey of an e-commerce website from the homepage to the Add to Cart stage.

The objective is to identify strengths, areas for improvement, and opportunities to enhance the overall user experience.

## Customer Journey
Homepage → Browse Categories or Search → Product Listing Page → Product Detail Page → Select Size → Add to Cart

## Business Analysis Deliverables
- Customer Journey Analysis
- Flowchart
- Strengths & Areas for Improvement
- Business Requirements
- Functional Requirements
- Non-Functional Requirements
- Prototype
- User Acceptance Testing (UAT)

## Key Areas for Improvement
- Mini Cart Functionality
- Product Image Navigation
- Product Comparison Feature
- Promotional Campaign Layout
